AGE动漫 视频下载器  v1.2   使用说明
================================================

【这是什么】
  一个 Windows 图形界面工具，用来把 AGE动漫（age001.com）上的番剧
  下载到本地，并直接封装成 MP4 / MKV。
  内置 ffmpeg，不需要另外安装任何东西，也不需要 ffmpeg 的安装路径。

  注意：请勿把本程序放在 D:\deepseekproject 目录下运行。
  该目录有系统级写入限制，会导致封装失败、只留下 .raw 文件。
  放在 D:\ 下的其他目录、桌面、或其他盘都可以。

【命令行用法】（不开界面，适合批量）
  在程序目录打开 cmd / PowerShell：

  AGE下载器.exe --cli <播放页地址> -n 1-13 -f mp4 -o "D:\视频"

     -n, --episodes   要下的集：1 / 1-3 / 1,2,5 都行（默认 1）
     -o, --out        保存目录（默认 用户目录\Downloads\AGE动漫）
     -f, --fmt        输出格式 mp4 或 mkv（默认 mp4）
     -w, --workers    并发数（默认 16，网络差就调小到 8）
     --keep-ads       保留片源里的广告段（默认自动剔除）
     --keep-segments  保留下载的分片缓存（默认删掉）

  进度会写到程序目录下的 cli.log。


【自检】
  AGE下载器.exe --selftest
  会打印 ffmpeg 路径、解析结果、7 个数据源条数、搜索测试，
  并写一份 selftest.txt 到程序目录。用来确认网络和内置 ffmpeg 正常。


【常见问题】

  问：双击后没反应 / 被杀毒拦了？
  答：本程序用 PyInstaller 打包，部分杀软会误报。加到白名单即可。
      另外必须保留整个文件夹（含 _internal 目录），只拷 .exe 无法运行。

  问：为什么只有 MP4 和 MKV，没有 TS？
  答：本机装有透明加密驱动，.ts 扩展名会被接管成加密容器，
      导致播放器打不开。所以全程用 .raw/.seg 做中间文件，
      成品只能选 MP4 或 MKV —— 两者都是无损封装，画质和原片一模一样。

  问：下载到一半提示某几集失败？
  答：把并发数调小（比如 8 或 4）再试一次。
      程序会自动重试 5 轮，仍失败的集会在日志里标出来。

  问：目录里出现 .raw 文件怎么办？
  答：那是没封装成功的中间文件。改用程序目录里的 convert_raw.py
      可以批量补转：
        python convert_raw.py "D:\你的目录"
      默认转换成功后删除 .raw，加 --keep 可保留。
